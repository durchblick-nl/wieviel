## Qui exploite ce site

calcule.ch est exploité par [Durchblick Consultancy BV](https://durchblick.nl/). Pour toute question concernant vos données ou pour demander leur suppression, utilisez les coordonnées indiquées sur le site de l’entreprise.

## Calculs et stockage nécessaire

Les données saisies et les résultats des calculateurs sont en principe traités directement dans votre navigateur. Une exception concerne les données externes : lorsque vous recherchez une commune dans le calculateur de coût de l’électricité, le terme recherché est transmis au service public `lindas.admin.ch` pour obtenir les tarifs d’ElCom. Si vous utilisez une fonction de partage, vous transmettez vous-même le résultat au service choisi.

- `wv_consent` conserve votre choix concernant l’analyse d’utilisation pendant 180 jours sur **calcule.ch**. Le choix est enregistré séparément sur wieviel.ch.
- `darkMode` conserve le thème clair ou sombre localement dans votre navigateur jusqu’à la suppression des données de navigation.
- Les polices et les icônes sont hébergées directement sur ce site. Aucune connexion à Google Fonts ou à un CDN d’icônes n’est nécessaire.

## Analyse d’utilisation facultative

Nous ne chargeons OpenPanel depuis `openpanel.dev` qu’avec votre accord. Il mesure alors les visites, les liens sortants et les interactions, avec la langue du site et le calculateur utilisé. Les données d’analyse sont transmises à `opapi.treehouse.ch`. Le script OpenPanel n’est pas chargé avant votre accord. Vous pouvez retirer votre accord à tout moment ci-dessous ou dans le pied de page ; le rechargement de la page met alors fin au script déjà actif.

## Fonctionnement du site

Le site est hébergé sur un serveur Hetzner en Allemagne. Cloudflare est utilisé comme proxy en amont. Lors d’une visite, des données techniques de connexion, notamment l’adresse IP et l’heure d’accès, sont traitées pour fournir et protéger le site. Ce traitement est distinct de l’analyse facultative avec OpenPanel.
